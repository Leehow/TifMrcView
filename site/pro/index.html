    TifMrcView Pro

    不只是看，还能分析。

    TifMrcView Pro 是在查看器之上做成的分析工具：3D 体视图、分割、SAM 2.1 智能分割、CTF 拟合和漂移校正。同样免费开源，计算尽量放在 GPU 上（CUDA、Metal、DX12、Vulkan）。

    macOS · Windows · Linux

    3D 体视图

    最大强度投影、半透明和等值面渲染。像 ChimeraX 那样按 σ 调阈值，平滑和直方图都在 GPU 上算。冷冻电镜断层可一键反相。

    分割标签与材料

    画笔、魔棒、阈值、分水岭、套索和层间插值。材料像 Amira 那样可命名、配色、隐藏和锁定，存成 Fiji / napari 能读的 16 位 TIFF。

    SAM 2.1 智能分割

    点一下就分出物体，再沿 Z 自动传播到整个物体，细膜和闭合轮廓也能跟住。模型用 Rust 重写，在你的显卡上本地运行，数据不出电脑。

    CTF 拟合

    在功率谱上拟合离焦、像散和相位板相移，把拟合出的 CTF 零点画在谱上，并给出一维拟合曲线。

    漂移校正

    测出影片、倾转系列和连续切片每一层的位移，画出轨迹，保存对齐后的栈或叠加图（MRC）。

    衍射标定

    自动找出单晶衍射的斑点和中心，拟合二维倒易晶格，在图上标出每个斑点的 (hk) 和 d 值；给出晶胞参数还能按带轴匹配。

    两个版本，各有侧重

    基础版：轻巧的查看器

    小而快，双击就开数 GB 的 TIFF / MRC。手动测量、标注、FFT 和能谱查看都有。适合日常浏览和快速检查，也有安卓版。

    基础版介绍

    Pro：分析工具

    包含基础版的全部功能，另加 3D、分割、SAM、CTF 拟合和漂移校正。适合要出结果的分析工作。可以和基础版同时安装。

    打开 2 GB MRC 后的内存

    所有进程的物理内存合计。TifMrcView 不会一次读入整个文件，而是先显示当前层，再在后台预读附近的层，最多用内存的 1/4；这台 32 GB 的电脑放得下整个文件，所以全部预读了。3dmod 默认把数据转成 8 位，所以更少。

    Pro2202 MB
    Fiji3803 MB
    IMOD 3dmod701 MB

    测试机：MacBook Pro（M1 Max，32 GB 内存，macOS 27），2026 年 10 月。TifMrcView Pro 0.7.56、Fiji（ImageJ 2.16.0 / 1.54p）、IMOD 5.1.13。每项取多次运行的中位数，磁盘缓存是热的，越短越好，打开时间含程序启动。Pro 的内存里包括后台预读的层（最多用内存的 1/4）；3dmod 默认把数据转成 8 位，所以内存更少。
