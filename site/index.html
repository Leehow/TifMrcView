    一个又小又快的显微图像查看器。双击 .tif / .tiff / .mrc 就能打开，拖动拉条翻 Z 层，多通道彩色合成，一个文件夹里的图左右切换。

    macOS · Windows · Linux

    下载

    macOS
    macOS 11 及以上
    首次打开若被拦截：到「系统设置 → 隐私与安全性」点「仍要打开」，或在终端运行 xattr -dr com.apple.quarantine /Applications/TifMrcView.app
    Windows
    无需管理员权限
    如果 .tif 以前被别的程序占用，在 TifMrcView 里点「设为默认」，系统设置里选一下即可。
    Linux
    x86_64
    AppImage 自带运行库，下载后 chmod +x 即可运行。

    功能

    ⚡

    打开即看

    内存映射读取，多核并行解压，后台预解码相邻 Z 层，拖拉条直接出图。

    ≡

    Z / T 拉条

    拖动或用方向键翻层，空格播放；带时间维度的数据另有 T 拉条。

    ◐

    多通道合成

    勾选显示通道、换颜色，每个通道单独调亮度、对比度和 γ。

    ▦

    文件夹浏览

    侧边缩略图列出同目录的图像，上下键切换文件，不用回到 Finder。

    📏

    标尺与测量

    按像素尺寸显示比例尺，画线测长度，一键导出整图或选区为 PNG。

    🗂

    格式齐全

    TIFF（LZW/Deflate/JPEG，8–32 位）、OME-TIFF、ImageJ hyperstack、MRC/MRC2014，以及常见图片格式。

    插件市场

    录制、蔡司 SmartSEM 元数据、专注模式……按需下载，在应用里一键加载。

    浏览插件

    快捷键

    ↑ ↓上一个 / 下一个文件
    ← →切换 Z 层
    空格播放 / 暂停 Z
    F 或双击适应窗口
    ⌘/Ctrl S保存 PNG 到当前目录
    ⌘/Ctrl O打开文件
