    TifMrcView

    看 TIFF 和 MRC，就该这么快。

    又小、又快、又方便。免费开源。

    显微与电镜图像查看器：TIFF、OME‑TIFF、MRC，数 GB 的栈双击即开。装上插件，还能打开蔡司 CZI、读出 SmartSEM 采集参数。macOS、Windows、Linux 通用。

    免费下载 所有版本
    macOS · Windows · Linux

    冷冻电镜 · MRC

    GB 级断层，拖动即达。

    文件直接映射进内存，多核并行解码，离当前层越近的，越先在后台备好。拖动 Z 拉条，画面跟手。

    XY · XZ · YZ

    换个角度，看清结构。

    一键切到侧视图，沿 Z 轴剖开整个体积。在任何切面上画框，宽与高直接标在图上。

    测量与标注

    每一笔，都是真实尺寸。

    线、框、圆与自由画笔，按像素尺寸换算成 nm、µm。

    • 比例尺自动叠加，导出的 PNG 里原样保留
    • 同名的 IMOD 模型（.mod / .fid）自动叠加
    • 标注按 Z 层记录，画完自动保存
    • 绘制、移动、删除、裁剪，都能撤销

    荧光 · 多通道

    每个通道，恰到好处。

    逐个通道开关、换色、单独调对比度，每一层自动计算显示范围。OME-TIFF 与 ImageJ hyperstack 原生读取；装上 Zeiss ZEN 插件，即可打开 CZI，物镜、激光、探测器等参数随图显示。

    文件夹缩略图

    同目录的图像排在侧栏，↑ ↓ 切换文件。

    逐层自动对比度

    默认 0.1% 饱和自动拉伸，也可以在直方图上直接拖选。

    Z / T 播放

    空格播放 Z 层；带时间维度的数据另有 T 拉条。

    裁剪与导出

    框出局部单独查看，按原始分辨率导出 PNG。

    图像信息

    格式、尺寸、像素尺寸和采集参数，一处查看，可搜索、可复制。

    自动更新

    新版本一到就提示，一键下载、校验签名并重启。

    浏览插件

    下载 TifMrcView。

    免费。macOS、Windows、Linux 原生安装包。

    macOS
    macOS 10.15 及以上
    首次打开若被拦截：到「系统设置 → 隐私与安全性」点「仍要打开」，或在终端运行 xattr -dr com.apple.quarantine /Applications/TifMrcView.app
    Windows
    无需管理员权限
    如果 .tif 以前被别的程序占用，在 TifMrcView 里点「设为默认」，系统设置里选一下即可。
    Linux
    x86_64 · deb · rpm · AppImage
    AppImage 自带运行库，下载后 chmod +x 即可运行。

    快捷键

    ↑↓上一个 / 下一个文件
    ←→切换 Z 层
    空格播放 / 暂停 Z
    F 或双击适应窗口
    SVMPREC选择 · 移动 · 测量 · 画笔 · 框 · 圆 · 裁剪
    H显示 / 隐藏标注
    ⌘/CtrlZ撤销 / 重做
    ⌘/CtrlS保存 PNG 到当前目录
    ⌘/CtrlO打开文件
