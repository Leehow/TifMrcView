    下载

    macOS
    macOS 10.15 及以上
    首次打开若被拦截：到「系统设置 → 隐私与安全性」点「仍要打开」，或在终端运行 xattr -dr com.apple.quarantine /Applications/TifMrcView.app
    Windows
    无需管理员权限
    如果 .tif 以前被别的程序占用，在 TifMrcView 里点「设为默认」，系统设置里选一下即可。
    Linux
    x86_64
    AppImage 自带运行库，下载后 chmod +x 即可运行。

    功能

    ⚡

    打开即看

    安装包只有几 MB。内存映射读取、多核并行解压、后台预解码相邻 Z 层，数 GB 的栈也能立刻翻。

    ≡

    Z / T 拉条

    拖动或用方向键翻层，空格播放；带时间维度的数据另有 T 拉条。

    ◐

    多通道合成

    勾选显示通道、换颜色，每个通道单独调亮度、对比度和 γ。

    ▦

    文件夹浏览

    侧边缩略图列出同目录的图像，上下键切换文件，不用回到 Finder。

    📏

    标注与测量

    画线、框、圆，按物理单位（nm / µm）显示长度、宽高，叠加比例尺，一键导出整图或选区为 PNG。

    🗂

    格式齐全

    TIFF / OME-TIFF / ImageJ hyperstack、MRC（冷冻电镜 / 冷冻电子断层）、蔡司 CZI、SmartSEM TIFF，以及 PNG / JPEG 等常见图片格式。

    ⤢

    XY / XZ / YZ 视图

    三维数据随时切换正面、侧面、顶面，在任意视角上标注和测量。

    🖥

    三大平台

    macOS、Windows、Linux 都有原生安装包，只有几 MB，下载即用。

    🧩

    插件，无限扩展

    录制视频、采集参数、自定义格式……按需安装插件，让 TifMrcView 长成你需要的样子。浏览插件 →

    插件市场

    录制视频、蔡司 SmartSEM 和 ZEN 采集参数……按需下载，在应用里一键加载。
